# Projects

Selected academic and programming projects. This page lists work with materials that are already available to share.

## Stock Price Forecasting with ARIMA in R

A time-series modeling exercise exploring **ARIMA** for stock-price forecasting, using TSMC price data as an example.

- **Topics:** time series, ARIMA, R, financial data
- **Material:** [Project poster (PDF)](https://github.com/user-attachments/files/18981707/_._m1124102.pdf)

This project is an academic modeling exercise, not an investment recommendation or a claim of reliable forecasting performance.
